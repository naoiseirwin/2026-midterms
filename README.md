# US 2026 Midterms Forecast

A single-page, static forecast of control of the US House and Senate in the 2026 midterm elections.

- `index.html` is fully self-contained (inline CSS, JavaScript and SVG maps). It makes no network requests.
- `retro.html` (when present) is the provisional results retrospective, built by a separate script; it is also self-contained.
- `.nojekyll` tells GitHub Pages to serve the files as they are.

To publish with GitHub Pages: push these files to a repository, then in **Settings → Pages** choose
"Deploy from a branch" and select the branch and the root folder.

Figures from markets and other forecasters are shown for comparison only and are not used in the forecast.
Values marked "to confirm" could not be checked against the original source.
